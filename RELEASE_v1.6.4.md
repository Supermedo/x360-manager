## Highlights

- **DashX360-style Metro console** — enable in Settings → **Beta Metro Console**
- **Home hub** — Last played, Favorite, Most played, and Game List tiles
- **Search channel** — search your library with controller/keyboard support
- **Settings blade** — 4×2 green tile grid (System, Preferences, Profile, Kinect, etc.)
- **Boot video** — DashX360 boot screen plays when entering console mode
- **Tab slide animations** — full left/right slide when switching search / home / games / settings
- **Dashboard sounds** — Page Left / Page Right on tab changes (DashX360 audio)
- **Favorite (X)** — pin games from hub, library, and game options
- **Profile editor** — Xbox 360 blade-style overlay with controller support
- **Centered overlays** — settings and profile panels open in the middle of the screen

## Download

Install **X360-Manager-Setup-1.6.4.exe** (Windows 10/11, 64-bit).

## Setup

1. Enable **Beta Metro Console** in App Settings if it is not already on
2. Open **Console Mode** from the game library to see the Metro dashboard
3. Use **LB / RB** to switch tabs; **X** to favorite; **Y** for game options

## Changes since v1.6.3

- Metro dashboard channels: search, home, games, settings
- Home hub layout (4 tiles: game list, last played, favorite, most played)
- Console boot sequence with Boot Screen video + startup sound
- Tab cross-slide animation and background parallax
- Search input fix (Backspace/Delete works while typing)
- DashX360 page navigation sounds on all tab switches
